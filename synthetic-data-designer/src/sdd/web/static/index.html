A closed pool holds every loan at the first cut-off and only shrinks. An open one keeps lending: loans written during the window appear at the cut-off they were written on, and are aged from there.

Transition matrix

Each row is a state, each column where a loan might be next period. Rows must sum to 1 — the total is live, and turns red if it does not.

YAML
